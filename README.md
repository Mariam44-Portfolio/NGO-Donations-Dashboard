# NGO Donations Dashboard | Excel

NGO Donations Dashboard in Excel - $25.9M raised vs $122M budget, 4,998 donations analysed.

**By:** Mariam Abdullateef | **Date:** Nov 2026
**Tool:** Microsoft Excel (Pivot Tables, Pivot Charts, Slicers)

## Overview
Analysed 4,998 NGO donations to track fundraising performance against budget across years, regions, and donor types.

## Key Metrics
- Total Donation: $25,976,215.89
- Total Donations Count: 4,998
- Average Donation: $5,197.32
- Total Budget: $122,021,185.93
- Achievement: ~21.3% of budget raised

## Dashboard Includes
1. Total Donation by Year (2021 - 2023)
2. Donation by Donor Type
3. Donation by Region (East, West, North, South)
4. Budget vs Actual by Region

## Insights
- Fundraising fell short of budget, showing a large funding gap.
- 2021 and 2022 performed stronger than 2023.
- East region contributed the most donations.
- Budget vs Actual comparison shows all regions underperformed against target.
